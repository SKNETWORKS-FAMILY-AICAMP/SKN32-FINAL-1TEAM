- 사람 수정 4쌍: 의미 차이를 지적한 메모 2쌍, 표현·초점 수정 2쌍.

## 2. 분석 범위와 방법

33개 신호가 32쌍에 발생했다. EDU-05-01 P3은 new_content와 new_purpose가 겹친다. 이는 사람 채택 기준의 경고 부담이며, 현재 모든 자료가 독립된 본문 전용 정답셋이라는 뜻은 아니다.

### 주체 추출: 가장 명확한 구현상 문제

실제 정규식이 잡은 문자열을 분석 산출물에 저장했다.

- `국가 ` → 끝의 가를 조사처럼 처리하여 국을 후보 주체로 취급.
- `운영하는 `, `활용하는 `, `알리는 ` → 관형형 어미를 조사처럼 처리.
- `정책적 메시지를 젊은 ` → 젊은의 은을 기준으로 앞의 어휘를 묶음.
- `아이 ` → 고유명사 끝 글자를 잡아 내용어가 없는 빈 주체 집합 생성.
- `성과 요소가 `, `사업자 설명회 등이 ` → 실제 조사 보충도 기존 생략형과 비교하면 주체 변화로 경고.

따라서 정규식의 끝 글자 검사만 바꾸는 것으로 끝내지 않고, 관형형/조사 구분 및 생략된 주어의 명시와 실제 주체 교체를 구분해야 한다. 단순히 주체 경고를 전부 끄는 것은 해결책이 아니다.

### 목적 신호: 표지 등장과 의미 관계를 혼동

예: `지원하여 돌봄 공백 해소` → `돌봄 공백 해소를 위해 지원`, `제작·방영하여 역할 강화` → `역할 강화를 위해 제작·방영`은 사람이 채택한 변형이다. `확대 기반` → `확대를 위한 기반` 같은 명사구 내부 풀어쓰기까지 문장 전체의 새 목적처럼 본다.

반대로 나란한 두 과제를 목적·수단으로 바꾸는 실제 오류는 경계해야 한다. 기존 도전 사례 CA-13의 미탐이 있으므로 위해/위한이 생긴 모든 문장을 허용하는 방향도 부적절하다. 목적의 내용뿐 아니라 어느 행위에 걸리는지를 확인해야 한다.

### 내용어 신호: 어휘량과 정보량을 혼동

예: `조속한` → `빠른 시일 안`, 이해관계자 → 이해/관계자 분할, 출결 → 출/결 분할, `방식·일·한편` 등의 풀이말 증가가 경고 근거에 포함된다. 그러나 실제 행위 변경인 운영→운행은 한 단어 교체라 내용어 추가 개수 기준을 만족하지 않는다.

개선 시 흔한 풀이말을 무조건 삭제하는 예외 목록보다 형태소 경계 정규화와 행위·대상별 대응을 우선한다. 특히 제공·지원처럼 한 단어만 추가돼도 의미가 달라질 수 있는 경우를 큰 어휘 증가량으로만 판단하지 않는다.

## 8. v3 개선에 사용한 우선순위와 완료 기준 — 제안 당시 기록

1. **주체 정규식의 오인 수정:** 국가·아이·관형형 어미와 조사 생략/보충을 정상으로 처리할 근거 마련. 실제 주체 교환의 탐지를 같이 확인.
2. **목적·내용어 경고의 근거 개선:** 원래 논항·관계와 명사구 수식을 대조하고 형태소 분할 차이를 보완. 단순 표지 등장·단어 수만으로 내던 경고를 정리.
3. **작은 의미 변화 보완:** 강도, 행위·기능 범위, 병렬 상태/조건의 적용 대상을 확인. 기존 미탐 10건을 비교 자료로 유지하고 assistant 수정 전 사례는 미확정 개발 후보로 취급.

개선은 v2를 보존한 별도 버전에서 진행한다. 우선 1~2의 수정으로 정상 경고가 어떻게 달라지는지 확인하고, 3의 범위를 한 번 정해 수행한다. 해결하지 못한 부분은 보류/사람 확인으로 남기며 완벽한 의미 판정기를 만들 때까지 SFT를 막지 않는다.

완료 보고에는 135쌍의 정상 경고 전후, 기존 84건의 동일 제외 조건·혼동행렬, 오류 유형별 손실/이득, 수정 사례의 신호 근거가 실제 우려와 맞는지, 남은 한계를 포함한다. 기존 TP 51건이 빠졌다면 사례별로 회귀 여부를 확인하고 근거 없이 누락을 수용하지 않는다. 라벨 변경이나 전체 신호 비활성화로 개선 점수를 만들지 않는다.

추가 전수 사람 검수는 하지 않는다. 기존 원시 입력을 확정 양성 평가 라벨로 꼭 사용해야 하는 별도 목적이 생길 때에만 필요한 경계 사례를 별도로 다룬다. 이번 작업에서는 새 사람 판정을 요청하거나 독립 judge를 호출하지 않았다.
