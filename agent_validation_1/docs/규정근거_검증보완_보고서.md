# 검증 1 규정 근거·자료 역할 보완 보고서

## 자료 역할 정책

공고는 공식 조건, 양식은 구조 기준, 최신 관리기준은 수행·사업비 기준, FAQ는 해석 보조, 과거 자료는 참고용으로 분리한다. FAQ와 참고자료는 확정 사실의 직접 근거로 사용하지 않는다.

## 항목별 검증

각 항목은 전용 키워드로 원문을 검색하고 `matchedKeywords`, `relevance`, `evidenceRoles`, `rationale`, `excerpts`를 결과에 저장한다. `high`·`medium`만 의미 검증에 전달하며 `low`는 추적용으로 남긴다.

## 판정

공식 조건·필수 양식 위반은 fail, FAQ 해석 차이·제안값 구체화 부족은 warning 또는 확인 필요로 기록한다. `provided`, `proposed`, `needs_confirmation` 상태를 구분한다.

## 재현성

결과 JSON의 `criteria`에서 적용 규정, 자료 역할, 키워드, 연결 사유, 발췌를 확인할 수 있다. 기존 결과에는 새 메타데이터가 없을 수 있으므로 기존 결과 검증·조립으로 갱신한다.

## 전체 재작성 전 점검 결과

일반·예비·초기 문서 유형의 모든 기준 로딩과 매핑을 확인했다. 공통 키워드는 제거되었고, 낮은 관련도 근거는 의미 검증 프롬프트에서 제외된다. 규정 매핑의 자료 역할·권위 수준·직접 사실 사용 가능 여부가 누락되지 않았다. F16 변경을 확인하려면 작성 재실행이 필요하고, F19 메타데이터만 갱신하려면 기존 결과 검증·조립으로 충분하다.
