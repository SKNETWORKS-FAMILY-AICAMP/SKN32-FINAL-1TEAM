# 2026-10-07 검증 1 보완 보고서

## 문제

협력기관 정보를 `partners[0]` 형태로 작성했지만 원본은 `resources.partners[0]`에 보존되어 `원본에 없는 fact 경로`로 판정될 수 있었다. 또한 검증 코드가 변경되어도 정책 버전이 같으면 이전 판정이 재사용될 수 있었다.

## 조치

- 배열 경로를 해석하는 `_at()`를 보완했다.
- `partners`, `equipment`, `hiring` 평탄화 경로를 `resources` 원본과 비교하는 `_fact_at()`를 추가했다.
- `validation_rubric.json` 버전을 `2026-10-07.1`로 갱신했다.
- 선택 검증 뒤 전체 결과 상태와 평가 요약을 다시 집계하도록 연결했다.

## 결과

수정된 검증 코드에서 `resources.partners[0]`·`resources.partners[1]` 조회를 확인했고, Python 문법 검사와 회귀 테스트 19개를 통과했다. 기존 JSON에 저장된 실패 상태는 자동으로 바뀌지 않으므로 서버 재시작 후 해당 항목 검증을 다시 실행해야 한다.
