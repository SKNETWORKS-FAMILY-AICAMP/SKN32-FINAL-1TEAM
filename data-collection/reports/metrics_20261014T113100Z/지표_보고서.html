다시 뽑는 방법

PowerShell 에서 아래 두 줄을 실행한다.

cd data-collection
.venv\Scripts\python.exe -X utf8 -m eval.metrics_report --all
  • 공용 DB는 읽기만 한다(쓰지 않는다).
  • 배치 서버의 배치 기록(로그)을 읽기 전용으로 복사해 온다.
  • 평가 질의 58개를 이 PC의 공고 서버와 실제 서버에 보내 응답을 잰다.
  • 단위 테스트를 돌린다.
  • 결과는 새 폴더 reports/metrics_<UTC 시각>Z/ 에 쓴다. 이전 결과 폴더는 덮지 않는다.
  • 서버 주소는 옵션으로 바꿀 수 있다(팀 계정으로 옮긴 뒤에는 새 주소를 넣는다).

보고서 두 파일(HTML·Word)만 다시 만들 때: .venv\Scripts\python.exe -X utf8 -m eval.metrics_doc reports\metrics_<UTC 시각>Z

metrics.json 의 값을 그대로 옮긴 문서다. 만든 곳: eval/metrics_doc.py
