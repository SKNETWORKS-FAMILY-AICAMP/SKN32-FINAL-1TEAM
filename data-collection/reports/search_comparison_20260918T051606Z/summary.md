# 임베딩 단독(dense) · 하이브리드(hybrid) 검색 비교 — 요약

실행 2026-09-18 · Claude · 지시서 [SEARCH_COMPARISON_TASK_20260918.md](../../docs/SEARCH_COMPARISON_TASK_20260918.md)

이 문서는 **10개 입력에서 실제로 무엇이 달라졌는지**를 적은 것이다.
전체 검색 품질의 우열이나 통계적 유의성을 말하지 않는다(사례 10개로는 알 수 없다).
사용자 판정 칸은 비워 두었다 — `human_review.csv`.

## 1. 비교한 조건

| 항목 | 값 |
|---|---|
| 공고 | 2,285건 (DB · Chroma · BM25 · 서버 표시용 정보의 **공고 ID 집합이 모두 동일**함을 확인) |
| 임베딩 | BAAI/bge-m3 · 입력 계약 `v1:title+body+target_text+target_category+category+subcategory` |
| 검색 설정 | top 5 · 가중치 기본값(dense 1 · bm25 1 · rrf_k 60 · mode order) · 리랭커 사용 안 함 |
| A 단계 | 마감 숨김·집단·시·도·시·군·구 **모두 끔** → 검색 방식 자체의 차이 |
| B 단계 | 위를 모두 켬 → 현재 서비스에서 사용자가 보는 결과 |
| 입력 | 정상 8(분야별) + 무관 2 · 원래 qid 와 선정 이유는 `inputs.jsonl` |
| 응답 | 10입력 × 2단계 × 2방식 = 40개 (`responses.jsonl`) |

**입력 3건(case01·02·03)에는 소재지가 없어 가상으로 더했다**(경기 수원시 / 서울 강남구 / 전남광주 목포시).
질의 파일은 바꾸지 않았다. 나머지 7건은 소재지가 비어 있어 지역·시·군·구 규칙이 걸리지 않는다.

각 쌍은 `search` 값만 다르다(자동 확인 통과). 모든 응답이 5건을 채웠고, 검색 깊이 50·1라운드였다.

## 2. 무엇이 달라졌나 (사실)

```
A 단계  상위 5칸 중 공통 18/50 · hybrid 에만 나온 공고 32건 · 공통 공고의 순위 이동 14건
B 단계  상위 5칸 중 공통 20/50 · hybrid 에만 나온 공고 30건 · 순위 이동 17건
        10개 사례 모두 두 방식의 상위 5가 달랐다(완전히 같은 사례 0건)
```

**절반 이상이 다른 공고다.** 검색 방식을 바꾸는 것은 순서를 조금 흔드는 정도가 아니다.

B 단계에서 규칙이 실제로 뒤로 보낸 건수(상위 5에 남은 것 기준, 최대 5건까지 기록):

```
다른 시·도 전용        dense 15 · hybrid 15
다른 시·군·구 전용      dense  2 · hybrid  3
집단 근거 없음         dense  9 · hybrid 16
```

## 3. 사용자가 판단할 사례

아래 "관찰"은 **Claude 의 잠정 의견**이다. 사람 판정이 아니며 `human_review.csv` 에 반영하지 않았다.

### 하이브리드가 나아 보이는 사례

**case05 수출 (q021) — "산업용 밸브, 중동 시장 수출"**
```
dense   12대 국가전략기술 기술이전 수요 모집 · 실리콘밸리 GTM · [울산] 이전·창업기업
hybrid  실리콘밸리 GTM · [인천] 2026년 중동 상황 위기 대응 긴급 · 중동피해 긴급지원 지사화
```
**"중동"이라는 말이 그대로 들어간 공고를 단어 검색이 찾았다.** 의미 검색은 "수출"의 뜻만 보고
지역명은 놓쳤다. 다만 그 공고가 "중동 **피해** 긴급지원"이라 이 신청자에게 맞는지는 사람이 봐야 한다.

**case03 소상공인 (q016) — "10년째 한식당, 경영 개선과 운영자금"**
```
hybrid 에만  소상공인 비즈플러스카드 · [전남] 중소기업 육성자금
```
"운영자금"에 대응하는 자금 공고를 더 올렸다.

### 하이브리드가 나빠 보이는 사례

**case08 사회적경제 (q031) — "발달장애인 고용, 친환경 세제"**
```
dense   장애인 창업 컨설팅(0.6292) · [경남] 진주시 발달장애인 가족창업 · 장애인고용개선장려금
hybrid  [경남] 진주시 발달장애인 가족창업 · 선도기업 전략직종 직무개발 · 장애인고용개선장려금
```
의미 검색이 1위로 올린 "장애인 창업 컨설팅"이 하이브리드 상위 5에서 빠지고,
관련이 옅어 보이는 "직무개발" 공고가 들어왔다.

**case07 환경·에너지 (q026) — "공장 지붕 태양광 + ESS"**
```
dense   기후테크 아카데미 · [전북] 에너지산업융복합단지 · [광주] 벤처기업육성자금
hybrid  [경기] 에너지기술공유대학 · 무탄소에너지보증(해상풍력) · 에너지 창업 경연대회
```
양쪽 다 "태양광·ESS 설치 지원"으로 보이는 공고는 없다. **하이브리드 쪽이 교육·경연 성격으로 더 기울었다.**

### 판단하기 어려운 사례

**case01 제조 · case02 IT·SW · case04 콘텐츠** — 두 방식 모두 "AI 창업 교육/경진대회" 계열이 섞여 있다.
`[온라인] AI로 나만의 수익 사이트 만들기` 같은 공고가 양쪽에 공통으로 올라온다.
**검색 방식 문제라기보다 공고 데이터에 실제로 그런 공고가 많은 것으로 보인다.**

**무관 질의 2건 (case09·10)** — 어느 쪽도 "관련 없음"이라고 말하지 못한다.
```
case09 "점심 뭐 먹을까"     dense·hybrid 모두 착한가격업소 지정 공고
case10 "캠핑 갈 장소"       dense 녹색융합클러스터 · hybrid 청년창업플랫폼
```
유사도도 0.48~0.51로 정상 질의와 겹친다. **무관 입력을 걸러내는 장치는 지금 없다.**

## 4. 이 비교로 알 수 없는 것

- **어느 쪽이 전체적으로 낫다고 말할 수 없다.** 사례 10개이고, 사람 판정도 아직 없다.
- 기존 평가(`eval/evaluate.py`)의 P@3 숫자는 **마감·지역·집단 규칙을 적용하지 않은 결과**다.
  B 단계(사용자 노출 결과)를 그 숫자로 검증했다고 볼 수 없다.
- 주제 판정(qrels)은 자격 판정이 아니다. 자격 API 가 통과라고 해도 '모름' 항목이 있으면 자격을 보장하지 않는다.
- "이 단어 때문에 올라왔다"는 설명은 **순위 정보(의미 N위·단어 N위)에서 읽은 추정**이다.
  단어별 기여도를 계산한 것이 아니다.
- 소재지가 없는 7개 입력에서는 지역 규칙이 실질적으로 작동하지 않았다.

## 5. 다음 개선 후보 (사용자 판단용)

1. **무관 입력 차단** — 두 방식 모두 무관 질의에 그럴듯한 공고를 5건 돌려준다. 점수 하한선이나 별도 판정이 필요하다.
2. **업력·나이 조건을 칸으로 뽑기** — 상위 3칸의 65%가 업력 '모름'이다(`eval/gate_eval.py`).
3. **사람 판정 확보** — `human_review.csv` 를 채우면 이 10개 사례에 한해 두 방식을 사람 기준으로 비교할 수 있다.
4. 교육·경연 성격 공고가 여러 분야에서 반복 노출되는지 별도 확인.
