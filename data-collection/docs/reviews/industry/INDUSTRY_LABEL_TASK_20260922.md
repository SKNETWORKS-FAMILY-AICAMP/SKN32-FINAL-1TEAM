# 업종 판정 30건 — Codex 작업 지시서

2026-09-22 · Claude 작성 · 사용자 결정에 따라 Codex 가 판정한다

## 왜 Codex 가 하나

사용자가 "도메인을 잘 몰라 직접 판정하기보다 Codex 가 파악하는 게 낫다"고 결정했다.
그래서 이번 판정은 **사람 정답이 아니라 Codex 판정(AI 참고 정답)** 이다. 결과를 보고할 때 반드시 이렇게 구분한다.

- 이 판정으로 잴 수 있는 것: v3(gpt-4o-mini) 와 Codex 가 **얼마나 같게 읽는가**, 어디서 갈리는가.
- 잴 수 없는 것: 사람 기준의 정확도. 두 AI 가 같은 실수를 하면 드러나지 않는다.
- `docs/STATUS.md` 의 "사람 칸을 AI 추정으로 채우지 않는다" 원칙은 이번 작업에 한해 사용자 결정으로 예외를 둔다.
  기존 `label_sheet.csv`(사람용)는 비워 둔 채 보존한다.

## 입력 (읽을 것)

- `reports/industry_llm_sample_20260922T050255Z/label_documents.md` — 30건의 원문 발췌와 판단 기준.
  v3 LLM 이 받은 것과 **똑같은 발췌**다(`document_sha256` 로 확인됨).
- `reports/industry_llm_sample_20260922T050255Z/label_sheet.csv` — 번호·notice_id·제목·링크·document_sha256.

## 블라인드 — 판정이 끝나기 전에 열지 않는 것

같은 폴더의 `summary.md`, `results.jsonl`, `checkpoint.jsonl`, `meta.json`, 이전 실행 폴더
(`industry_llm_sample_20260922T022756Z`, `…T023053Z`), `docs/WORKLOG.md`·`docs/STATUS.md` 의 업종 LLM 결과 서술.
LLM 답을 먼저 보면 판정이 그쪽으로 쏠려 비교가 의미 없어진다. 판정은 **발췌만 보고** 한다.
(원문 링크로 공고 전체를 볼 필요는 없다. v3 도 발췌만 받았으므로 같은 조건에서 판정한다.)

## 판단 기준

`label_documents.md` 머리의 기준과 같다. 요약:

- **known**: 공고가 "어떤 업종만 신청할 수 있다"고 밝혔다. 허용 업종을 **원문 표현 그대로 모두** 적는다.
- **no_limit**: "업종 제한 없음"·"전 업종"·"업종 무관"처럼 업종에 제한이 없다고 **명시**했다. "누구나"만으로는 아니다.
- **unknown**: 업종 언급이 없거나, 제외 업종만 있거나, 애매하다.
- 업종이 **아닌** 것: 중소기업·소상공인·중견기업·스타트업·사회적기업·연구소기업 같은 규모·형태, 지원 분야·사업 주제,
  지역, 업력, 소상공인·중소기업 **정의**의 업종별 인원 기준("제조업·건설업: 상시근로자 10인 미만").
- "바이오 분야 중소기업"처럼 대상 기업을 분야로 **한정**하면 허용 업종으로 본다(원문 표현 그대로).
- 제외 업종: "OO업은 지원 제외"·"제외업종: …"처럼 그 업종에 제외가 붙은 것만.
- 목록완전: 허용 업종을 **이 발췌에서** 빠짐없이 알 수 있으면 Y, 별표·붙임·"등"으로 전부 알 수 없으면 N.
- 애매하면 unknown 으로 두고 확신도를 `낮음` 으로 적는다. 억지로 정하지 않는다.

## 출력

`reports/industry_llm_sample_20260922T050255Z/label_sheet_codex.csv` (UTF-8 BOM, 30행). `label_sheet.csv` 의 열을 그대로 두고
정답 칸을 채운 뒤 아래 세 열을 뒤에 붙인다.

| 열 | 내용 |
|---|---|
| 정답_상태 | known / no_limit / unknown |
| 정답_허용업종 | 원문 표현 그대로, `;` 로 구분. known 일 때만 |
| 정답_제외업종 | 원문 표현 그대로, `;` 로 구분 |
| 정답_목록완전 | Y / N / 모름. known 일 때만 |
| 메모 | 애매한 이유 |
| **확신도** | 높음 / 낮음 |
| **근거** | 판단 근거 문장을 발췌에서 **그대로** 복사. unknown 이고 근거가 없으면 빈칸 |
| **판정자** | `codex` |

- `notice_id`·`document_sha256` 는 바꾸지 않는다. 행 순서도 그대로 둔다.
- 30건을 다 못 하면 한 건도 추측으로 채우지 말고 빈칸으로 두고, 몇 건을 했는지 적는다.
