# 판정표 지문 신선도 3차 재검수 (2026-09-29)

대상: [Claude 3차 응답·재검수 요청](JUDGMENT_FRESHNESS_REVIEW_RECHECK2_RESPONSE_20260929.md), [직전 Codex 검수](JUDGMENT_FRESHNESS_REVIEW_RECHECK2_20260929.md).

## 결론

**코드 재검수 승인 — 지적한 P1 수정 확인.** 첨부 `['예비', '창업']` 경계의 가짜 언급이 발췌 밖 실제 언급을 가리던 입력에서, 서비스는 확인 필요(`None`), 13단계 행은 `pre_founder_verdict=NULL`이 됐다. 이전 반복 문구·단어 중간 공백·원문 없음·지문 불일치 처리도 유지됐다. 실행 중인 8000 서버의 재시작과 실제 업로드는 이 검수 범위에 넣지 않았다.

## P1 재현과 결론

[unread_pre_founder()](../../../search/applicant_types.py)는 원문을 지원대상·본문·첨부별로 세고, 발췌는 `document.split('\n\n')`의 각 조각을 따로 세어 합한다. 문장 표시용 문자열에도 조각 사이 `|`를 넣었다. [build_document()](../../../collect/extract_conditions.py)는 이번 수정에서 바뀌지 않았다.

직전 검수와 같은 입력을 실제 `prepare()`·`load_auto()`·`type_rows()`에 넣었다.

```python
old = prepare({
    'notice_id': 'n1', 'title': 'test', 'target_text': '',
    'body': '예비창업자 신청 불가. ' + 'A' * 2100,
    'attachments': ['예비', '창업'],
})
new = prepare({
    'notice_id': 'n1', 'title': 'test', 'target_text': '',
    'body': old['body'] + ' 예비창업자도 신청 가능.',
    'attachments': ['예비', '창업'],
})
```

| 확인 항목 | 이번 결과 |
|---|---|
| `old`/`new` 발췌 지문 | 같음. 새 허용 문장은 본문 2,000자 머리 밖이다. |
| `new` 원문 / 조각별 발췌의 `예비창업` | 2회 / 1회. 첨부 경계 `예비\n\n창업`은 발췌 횟수에 들어가지 않는다. |
| `unread_pre_founder(new)` | “예비창업자도 신청 가능”을 포함한 문장 조각 반환 |
| 옛 strong 불가 DB 행 + `load_auto(..., documents={'n1': new})` | `pre_founder('n1') is None`, `unread_pre_founder == 1` |
| 같은 결과 JSONL + `type_rows(path, {'n1': new})` | `pre_founder_verdict is None` (업로드 행의 NULL) |

## 조각별 횟수의 경계 확인

현재 [build_document()](../../../collect/extract_conditions.py)는 지원대상과 본문 머리를 각각 공백 정규화한 뒤 `\n\n`으로 잇고 최대 2,000자에서 자른다. 첨부별 발췌도 `\n\n`으로 잇는다. 머리와 첨부 사이에는 `[공고문 첨부 발췌]` 표시가 있으며, 한 첨부에서 떨어진 자격 구간 사이에는 `---`가 있다. 따라서 서로 다른 출처의 글자가 한 집계 조각에서 이어져 `예비창업`이 새로 만들어지는 경로를 코드에서 찾지 못했다. 머리 자르기와 첨부 예산 절단은 언급을 제거할 수는 있어도 늘리지 않는다.

자격 구간을 못 찾은 첨부는 원문 앞부분을 그대로 쓰므로, 그 안의 빈 줄이 한 **출처**를 두 집계 조각으로 나눌 수 있다. `예비\n\n창업`처럼 실제로 읽은 언급도 발췌 횟수에서 빠져 유효한 `blocked`가 확인 필요로 내려갈 수 있다. 이는 차단을 과하게 적용하는 방향은 아니며, Claude 응답에 적힌 보수적 처리 범위다.

머리 두 출처 경계, 2,000자 자르기, 첨부 경계, 첨부 예산 절단, 자격 구간이 없는 첨부의 빈 줄, 떨어진 자격 구간을 별도 입력으로 확인했다. 각 경우 조각별 발췌 횟수는 출처별 원문 횟수 이하였다. 같은 불변식을 고정 시드로 만든 입력 2,500건(지원대상·본문·첨부, 공백·빈 줄·자격 제목, 여러 예산 크기)에서도 확인했고 초과 사례는 0건이었다. 무작위 검사는 가능한 모든 입력의 증명이 아니며, 위 코드 경계 검토를 보조한다.
