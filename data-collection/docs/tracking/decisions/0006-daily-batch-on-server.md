# 0006. 매일 배치를 개인 PC에서 서버로 옮긴다

- 날짜: 2026-10-02(서버 첫 실행 10/3 09:00) · 결정: 사용자

## 배경
매일 배치가 사용자 개인 PC 작업 스케줄러에서 돌아, PC가 꺼지거나 바쁘면 수집이 빠졌다. 배포 완료 목표는 10/25이고, 학원 AWS 계정은 나중에 받는다.

## 결정
개인 AWS 계정 EC2 `sbrain-web`에서 Docker `batch` 컨테이너로 돌린다(cron UTC 00:00). PC 예약은 지우지 않고 끈다. 같은 Docker 구성으로 나중에 학원 계정에 다시 올린다.

## 대안
- PC 유지: 가장 단순하지만 PC 상태에 묶인다.
- 팀 EC2(43.201.90.238)에서 돌리기: 4GB에 MySQL·Chroma와 BGE-M3 임베딩이 함께 올라가 메모리가 모자랄 수 있다.

## 결과
- **서버 코드가 git이 아니라 복사본**이라 PC에서 고친 배치 코드는 다시 복사해야 반영된다.
- PC의 벡터 파일·Chroma 색인이 멈춰, PC에서 켠 공고 서버의 의미 검색은 새 공고를 모른다.
- BGE-M3 리비전을 PC와 같은 값으로 고정해야 전량 재임베딩을 피한다.
