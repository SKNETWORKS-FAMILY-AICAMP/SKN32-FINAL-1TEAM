# 0003. 판정할 수 없으면 통과로 둔다

- 날짜: 2026-09-29 · 결정: 사용자

## 배경
조율 쪽 G-01 흐름은 "판정 불가"가 나오면 안내를 띄우고 공고 선택으로 되돌려 계획서 작성을 막는다. 기업마당 공고는 업력 칸이 없고 접수 마감일도 상당수 없어서, 판정 불가로 막으면 대부분이 막힌다.

## 결정
확실한 미달만 불합격(`failed_conditions`)이다. 조건을 못 읽음·입력 누락(설립일 없는 사업자 등)은 통과로 두고 `unknown_conditions`에만 적는다. 매칭의 "모르면 빼지 않는다"와 같은 원칙이다. 같은 날, 자격 판정은 접수기간을 보지 않기로 했다(접수 시작 전 공고도 고를 수 있다 — 매칭 정형 필터와 같다).

## 대안
- 판정 불가 = 불합격 또는 차단: 조건 정보가 적은 기업마당 공고 대부분을 고를 수 없게 된다.
- 판정 불가 = 사용자 확인 단계: 조율 흐름에 경고 칸이 없어 확장 합의가 필요하다.

## 결과
- "공고문을 직접 확인해 주세요" 안내가 조율 쪽 흐름에서 사라진다. 필요하면 `unknown_conditions`를 화면에 쓰도록 조율 담당과 합의해야 한다.
- 통과가 "자격 충족"으로 읽히지 않게 화면 문구를 조심해야 한다.
