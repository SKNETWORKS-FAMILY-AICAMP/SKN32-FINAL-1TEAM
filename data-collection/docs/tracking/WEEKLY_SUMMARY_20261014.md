## 한눈에

- **지난주**: 조율 Agent가 부를 공고 서버 API 4개를 만들어 시험 서버(`http://43.201.90.238:8000`)에 올렸다. 가산점 기능을 "틀린 점수보다 모름" 원칙으로 다듬어 원문 대조 27건만 화면·순위에 쓰게 했다. 검색에서 벡터 DB(Chroma)를 뺐고, 배치 AI 3단계를 gpt-6-luna로 바꿨다.
- **이번 주**: 배치와 공고 서버를 서버 한 대(4GB) + RDS로 옮기는 시험을 버튼 한 번으로 통과했다. 개인사업자·법인 "확실한 불가" 공고를 걸러 내고, 배치 경고를 보강했다. 발표 PPT 데이터 파트 2장을 만들고 팀 전체 배포를 점검했다.
