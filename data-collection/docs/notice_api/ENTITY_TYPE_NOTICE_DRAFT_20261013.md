# 조율 담당 알림 초안 — 개인사업자·법인 자격 판정 (2026-10-13 작성)

> **보내기 전 확인:** 이 초안은 아직 보내지 않았다. 보내기는 사용자(이근준)가 한다. 시험 서버에 결정 0021 코드를 올리고 확인(계약 시험)이 끝난 **뒤에** 보낸다.

---

공고 서버 자격 판정이 조금 바뀌어 알려 드립니다. **응답 키와 모양은 그대로**이고, 값만 달라질 수 있습니다.

**무엇이 바뀌었나**
- 지금까지는 공고 본문의 신청자 유형을 예비창업자에게만 판정했습니다. 이제 **개인사업자·법인도** 공고 본문에 그 유형이 확실히 안 된다고 적혀 있으면(예: "법인 제외", "국내 법인사업자만") 미달로 봅니다.
- 근거가 약하거나, 세부사업마다 다르거나, 공고문 다른 곳에 그 유형 언급이 더 있으면 예전처럼 "확인할 수 없음"으로 둡니다.

**응답에서 달라지는 값**
1. `POST /api/notices/{id}/eligibility` — 개인사업자·법인 신청자의 `지원대상 유형`이 `failed_conditions`에 들어가고 `passed`가 `false`가 될 수 있습니다(전에는 늘 `unknown_conditions`).
2. `GET /api/notices/{id}` — `eligibility.applicant_types`에서 `개인사업자`나 `법인`이 빠질 수 있습니다.
3. `POST /api/match` — 그런 공고는 추천 결과에서 빠지고, `filter.excluded`에 `개인사업자 불가(공고 본문)`·`법인 불가(공고 본문)` 이유가 생깁니다.

**규모(2026-10-13, 열린 공고 1,730건 기준)**: 개인사업자에게서 11건, 법인에게서 9건이 빠집니다. 추천 정형 필터와 자격 판정의 결론은 실제 데이터 17,826회 대조에서 모두 같았습니다.
