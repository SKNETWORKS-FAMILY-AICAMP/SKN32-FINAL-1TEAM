# 전략·작성 Agent 근거 기반 작성 보완 보고서

## 변경 목적

사업계획서 공고·양식·FAQ·관리기준을 동일한 사실 근거로 취급하지 않고, 자료의 역할과 항목별 적합성을 구분해 F16 작성과 F19 검증에 전달한다.

## 구현 내용

- 항목별 전용 키워드와 `sourceMappings` 적용
- 규정 자료 역할(`sourceRole`)과 권위 수준(`authorityLevel`) 저장
- 확정 사실 사용 가능 여부(`directFactAllowed`) 저장
- 근거별 키워드·관련도·적용 목적·연결 사유·발췌 저장
- 낮은 관련도 근거는 프롬프트에서 제외하고 결과 추적용으로 보존
- F16 작성 전에 항목별 기준과 관련 발췌 전달
- F19에서 동일 기준으로 구조·근거·상태 검증
- 선택 재작성 경로에도 문서 유형과 항목 기준 전달
- UI `criteria-hint`에 근거 유형과 연결 이유 표시

## 실행 기준

- 작성 정책 적용 확인: 선택 항목 재작성
- 검증 메타데이터 갱신: 기존 결과 검증·조립
- 전체 항목 적용: 전체 재실행

## 확인 결과

일반·예비·초기 문서 계약과 Python·JavaScript 문법 검사를 확인했다. 기존 결과는 새 메타데이터가 없을 수 있으므로 검증·조립을 통해 갱신한다.

## 전체 재작성 전 사전 점검

일반 10개, 예비 25개, 초기 24개 기준을 전수 검사했다. 공통 키워드 매핑과 관련도 낮은 프롬프트 전달이 없으며, 모든 예비·초기 규정 매핑에 자료 역할 메타데이터가 있다. F16 작성 정책 변경을 확인할 때는 전체 재작성 또는 선택 재작성, 기존 결과의 근거 메타데이터만 갱신할 때는 F19·F20 검증·조립을 사용한다.
