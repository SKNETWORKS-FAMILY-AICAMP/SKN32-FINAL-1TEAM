- 몰입과 상호작용: 3D, 스크롤 반응, AR, 게임화 등으로 정적 화면보다 참여를 강조한다.

## 제품 적용 우선순위 제안

1. 사용자 문제와 화면 목표를 먼저 정한다. 문서 탐색이라면 검색·가독성·접근성·반응형 구성이 우선 후보가 된다.
2. 애니메이션, 3D, AR은 콘텐츠 이해나 제품 체험을 개선하는 구체적 목적이 있을 때 작은 실험으로 도입한다.
3. 적용 후에는 접근성, 로딩 성능, 모바일 조작성과 사용자의 과업 완료율을 별도로 검증한다.
이 우선순위는 보고서의 실무 제안이며 수집 데이터가 실험으로 입증한 순위는 아니다.
