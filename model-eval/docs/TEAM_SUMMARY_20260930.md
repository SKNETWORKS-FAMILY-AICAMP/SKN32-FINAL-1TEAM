# S-Brain Agent별 모델 시험 결과 — 팀 공유용 요약

작성: 2026-09-30 · 담당: 이근준(시험 진행), Claude(코드·분석) · 상세: [인계서](HANDOFF_20260930.md)
**팀이 정한 결정이 아니라 한 사람이 자체적으로 시험한 결과다.** 모든 입력은 가상 샘플이고, 점수는 자동 채점이다.

## 한 줄 결론

> 지금까지 시험한 후보 중에서는 **`gpt-6-luna`가 가격 대비 가장 낫다.** `gpt-5.6-luna`와 대체로 같은 품질을 **절반 가격**에 낸다.
> `gpt-4.1-mini`는 여러 Agent에서 약점이 뚜렷했고, 비싼 모델(`terra`·`sol`·`astra`)은 값을 하지 못했다.

## 무엇을 어떻게 시험했나

- 대상: 조율(T-C1) · 전략(T-S1·T-S2) · 작성(T-W1·T-W2·T-W3) · 구현(T-B1·T-B2) · 검증-1(T-V1). 기획서 v1.10 5-2절의 "Agent별 모델 배치 방침"의 빈칸(구체 모델)을 채우는 시험이다.
- 방식: 가상 아이템 8건 등을 후보 모델에 같은 조건으로 넣고, **기능정의서의 규칙을 그대로 자동 채점 기준**으로 옮겨 재었다(섹션 1:1, 지원금 상한, 기능 목록 유지, 수치 출처, 접근성 등).
- 규모: 실험 5종 · 호출 **2,106건** · 비용 **$6.08**. 모두 OpenAI 모델이다.

## 알아 두면 좋은 발견

1. **비싼 모델이 낫지 않았다.** terra는 luna의 약 9~10배 비용인데 조율·전략·작성 어디서도 이점이 없었다. 기획서의 "추론 성능 우선 모델"은 비싼 모델을 뜻하지 않는다.
2. **추론 모델(luna)은 이 작업들에서 거의 생각하지 않는다**(평균 추론 토큰 수십~수백 개). 그래서 값이 싸다.
3. **gpt-4.1-mini의 반복되는 약점:** 없는 내용에 점수 주기, 자료가 없을 때 출처 지어내기, 입력에 없는 일정 만들기, 끼워 넣은 지시문에 속기. 가장 싸지만 서비스 품질 위험이 크다.
4. **시험이 쉬워 변별이 안 되는 Agent가 있다.** 조율과 구현은 대부분 천장(100%)이라 후보를 확정하려면 더 어려운 입력이 필요하다.
5. **구현에서 차이는 접근성의 "명도 대비"(글자와 배경 색 대비 4.5:1) 하나였다.** 기능 구현은 모두 100%.
6. **비용 감각:** luna 6 기준 한 번 끝까지 돌리는 데 실험 입력(짧은 문서)으로 약 **$0.01~0.02**. 실제 긴 문서면 몇 배로 늘 수 있다.

## 팀 코드에 반영하면 좋은 제안

- **T-S1의 `featureList`는 LLM이 다시 쓰게 하지 말고 코드가 `coreFeatures`를 그대로 복사한다.** 강한 모델일수록 기능 이름을 쪼개거나 풀어써서(terra 8/24, gpt-6-luna 6/24) 뒤 공정의 기준 목록이 깨진다.
- **T-S2(시장 분석)는 참고 자료를 넣어 주고, 자료에 없는 출처의 수치는 코드로 걸러낸다.** 모델에게 검색 도구가 없어서 그냥 시키면 지어낼 수 있다.
- **검증-1의 "온도 0 고정"은 추론 모델(luna)이 온도를 받지 않아 지킬 수 없다.** 재현성은 재채점 편차 감시(`varianceFlag`)로 확보해야 한다(luna의 편차는 약 1점, 70점 만점의 1.4%).
- **검증-1 rubric은 실제 공고 평가항목으로 바꿔 다시 시험해야 한다.** 이번엔 자체 기준(문서층 70점 구조만 맞춤)이었다.

## 한계와 아직 안 한 것

- 입력이 전부 **가상 샘플(AI 초안)**이라, AI가 쓴 글을 AI가 채점하는 편향이 남는다. 작성 글 품질 채점자(luna 5.6)는 luna 계열에 후할 수 있다.
- **사람 점수와의 일치도는 재지 않았다.** 검증-1이 특히 그렇다.
- 반복 3회(구현은 1회), 아이템 8건이라 작은 차이는 오차 범위다.
- 정적 파싱 채점이라 **프로토타입의 실제 동작·미관은 반영하지 않았다.** 리포트 갤러리로 눈으로 볼 수 있다.
- **채점 기준을 결과를 본 뒤 여러 번 고쳤다**(채점기 오탐 제거 위주). 무엇을 왜 고쳤는지 인계서에 적어 두었다.
- 시험하지 않은 것: 검증-2, 검수(자체 파인튜닝), Claude·로컬 모델(집 3060, RunPod), 사람 점수 대조.
