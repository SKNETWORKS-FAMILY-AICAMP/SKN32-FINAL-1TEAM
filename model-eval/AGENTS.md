# model-eval 작업 규칙

이 폴더는 S-Brain **Agent별 모델 비교 실험** 공간이다. Claude, Codex 및 다른 AI가 함께 따른다.
현재 사용자의 명시적 지시가 우선한다. 사용자는 이 실험을 팀 결정과 별개로 **자체적으로** 진행한다.

## 시작할 때

1. [인계서](docs/HANDOFF_20260930.md)를 먼저 읽는다. 결과·다음 단계·주의점이 있다.
2. [README](README.md)로 폴더 구조와 실행 방법을 확인한다.
3. 이 폴더 밖(`agent-orchestration/`, `data-collection/`)은 **읽기만** 한다. 팀 코드를 고쳐서 실험하지 않고, 필요한 것은 이 폴더 안에 새 파일로 만든다.

## 지킬 것

- **Git 커밋·push·스테이징은 사용자가 직접 한다.** AI는 실행하지 않는다.
- **유료 호출은 비용을 먼저 보여 주고 승인받은 뒤에만 한다.** 기본 실행은 계획만 출력한다(`--execute`가 있어야 호출). 예상 비용이 `--max-usd`(기본 1.0)를 넘으면 멈춘다.
- **`reports/` 안의 기존 결과 폴더를 덮어쓰지 않는다.** 매 실행은 새 폴더에 쓴다. 채점 기준이 바뀌어 표·리포트만 다시 만드는 경우(`python -m v1_verifier.report <폴더>`)에도 원본 `calls.jsonl`은 건드리지 않는다.
- **실험용 키와 비용(2026-09-30 저녁 사용자 결정): "너무 계산해서 쓰거나 그러진 말자, 일단 그냥 써."** 지금은 `data-collection/.env`의 키(개인 계정, 매일 09:00 배치와 같은 키, 충전 후 잔액 $12.17)를 실행 프로세스 환경 변수로만 넘겨 쓴다. 예상 비용은 한 줄로만 말하고, 수 달러 이내면 되묻지 않고 실행하며, 대략 $5 이상이 되는 실행만 먼저 묻는다. 실험 v1~v6 누적은 $6.60(`reports/index.html`). 배치는 하루 약 $0.165를 같은 키로 쓰므로 잔액이 바닥나면 배치가 멈춘다는 점은 알고 있을 것. 나중에 만들 새 계정(팀원들이 학원 지원 $300을 나눠 쓰는 공용 예산)으로 배치와 실험이 함께 옮겨 가면 그 키를 환경 변수 `OPENAI_API_KEY` 또는 `model-eval/.env`로 받고 그때는 아껴 쓴다.
- **API 키를 문서·로그·결과에 적지 않는다.** 환경 변수 `OPENAI_API_KEY` 또는 `model-eval/.env`(커밋 금지)만 쓴다.
- 채점 기준·프롬프트·계획서 샘플을 바꾸면 버전을 올리고(`rubric.json`의 `version`, `prompt.py`의 `PROMPT_VERSION`), **바뀌기 전 결과와 직접 비교하지 않는다.** 인계서 "결과"의 실행 표를 참고한다.
- **비싼 모델(gpt-6-sol·gpt-6.1-sol·gpt-6-astra·gpt-5.6-sol·gpt-5.6-terra)은 실험에 쓰지 않는다(2026-09-30 사용자 결정).** 후보는 luna 계열(gpt-6-luna, gpt-5.6-luna) 중심이다. 모델 목록을 볼 때 이름을 걸러 보지 말고 전체를 생성일 순으로 본다(새 세대를 놓친 적이 있다).
- 후보 모델을 추가할 때는 `candidates.json`에 한 줄만 더한다. 단가는 출처와 날짜를 함께 적는다.
- 결과를 말할 때 **측정 조건**(계획서 편수·반복 횟수·채점 기준 버전)을 함께 쓴다. 이 실험은 "노골적으로 망가진 글을 걸러내는가"만 보며, 사람 점수와의 일치도는 아직 측정하지 않았다.

## 작업 기록

- 이 폴더의 상태·결과는 [인계서](docs/HANDOFF_20260930.md)에 이어 쓴다(새 인계서는 날짜를 붙여 추가).
- 프로젝트 공용 기록은 `data-collection/docs/STATUS.md`와 `WORKLOG.md`에도 짧게 남긴다. 다른 AI의 항목은 지우거나 바꾸지 않는다.
- 여러 AI가 동시에 일하면 진행 중 작업을 각각 별도 항목으로 적는다.
