S-Brain 로그인 테스트 (프론트 완성 전 임시용)

아래 버튼으로 진짜 구글 로그인 → 받은 id_token을 백엔드 /auth/google에 그대로 던져본다. 로그인 성공하면 밑에 프로젝트 만들기 폼이 나타난다 — 실제 브라우저 세션(쿠키)으로 POST /projects까지 그대로 테스트할 수 있다.

이 페이지는 http://localhost:5174/login_test.html로 열어야 한다(127.0.0.1 아님) — 백엔드가 쿠키를 localhost:8000 기준으로 내려주는데, 브라우저 SameSite 판정에서 localhost와 127.0.0.1은 서로 다른 site로 취급돼서, 페이지를 127.0.0.1로 열면 로그인은 돼도 그다음 요청(프로젝트 생성 등)에 쿠키가 안 실려간다(app/security.py의 set_session_cookie 주석 참고). python -m http.server 5174로 띄운 뒤 반드시 localhost로 접속할 것.
